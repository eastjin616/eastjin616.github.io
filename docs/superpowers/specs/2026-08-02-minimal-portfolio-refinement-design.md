# 미니멀 포트폴리오 개선 디자인

작성일: 2026-08-02  
상태: 사용자 승인

## 목적

현재 포트폴리오의 작은 글씨, 넓은 여백, 종이색 배경, 가운데 프로필, 선으로 구분한 목록형 UI를 유지하면서 채용 담당자가 프로젝트 역할과 문제 해결 경험을 더 빠르게 파악하도록 한다.

지원 포지션은 Java/Spring 백엔드, 백엔드 중심 풀스택, AI 서비스·개발도구 엔지니어를 모두 포함한다. 한 직무에만 맞춘 표현 대신 웹 서비스, Go CLI, AI 제품, 운영·장애 대응 경험이 연결되어 보이게 한다.

## 변경 범위

### 소개

- 기존 프로필 구조와 크기를 유지한다.
- 추상적인 영문 소개를 실제 경험이 드러나는 짧은 한글 문장으로 바꾼다.
- 기술 스택과 링크의 배치 방식은 유지한다.

### 프로젝트 목록

- 현재 제목, 기간, 상태, 링크 구조를 유지한다.
- DEV.AI, IPCC, Plainpaper, Badukland 네 작업에 담당 역할과 해결 포인트를 요약한 한 줄을 추가한다.
- Plainpaper는 더 적합한 공개 런칭 서비스가 생기기 전까지 AI 서비스 대표 사례로 사용하되, 백엔드가 중단된 데모는 노출하지 않고 소스 링크만 제공한다.
- 상세 설명은 기존 케이스 페이지에 남기고 홈에서는 근거 세 개 이내만 노출한다.
- 카드, 배지 묶음, 대형 제목은 추가하지 않는다.

### 사이드 프로젝트와 교육

- 메인 화면에서 별도 Side Project 섹션을 두지 않는다.
- KH 정보교육원과 팀 스파르타 과정은 기간과 핵심 학습 범위를 한 줄로 표시하고, 선택하면 상세 모달을 연다.
- ThreeStars와 this.서고는 KH 정보교육원 상세 모달 안에서 문제 해결 포인트와 GitHub 링크를 보여준다.
- 팀 스파르타 상세 모달에는 Python·OCR·LLM·RAG 학습과 AI 서비스 구현 흐름을 보여준다.
- 실무 프로젝트보다 시각적 비중을 높이지 않는다.

### 경력

- 현재 목록과 상세 모달을 유지한다.
- 작은 표시와 hover/focus 상태로 행이 클릭 가능하다는 점만 명확히 한다.
- 모달을 열 때 포커스를 이동하고, Tab 키를 모달 내부에 유지하며, 닫은 뒤 기존 항목으로 포커스를 돌린다.
- 모달이 열린 동안 배경 스크롤을 막는다.

### 문서 메타데이터와 링크

- 외부 HTTP 링크는 새 탭에서 열고 `noopener noreferrer`를 적용한다.
- 기본 설명과 Open Graph 메타데이터를 현재 포지셔닝과 일치시킨다.
- 공유 이미지가 실제로 준비되지 않은 상태에서는 존재하지 않는 `og:image`를 추가하지 않는다.

## 시각 제약

- 현재 최대 폭 760px, 색상, 타이포그래피, 여백 체계를 유지한다.
- 큰 영문 헤드라인, 웨이퍼 그래픽, 카드형 갤러리, 다크 테마를 도입하지 않는다.
- 새 정보는 기존 선형 목록 안에 들어가며 별도 디자인 시스템을 만들지 않는다.

## 콘텐츠 원칙

- Notion 원문의 강점은 가져오되 검증되지 않은 성과 수치는 추가하지 않는다.
- DEV.AI는 Go CLI 단독 설계, API 호출 개선, 크로스 플랫폼 대응을 요약한다.
- IPCC는 IVR·ADNS 운영, DR 이중화, 로그 기반 장애 분석을 요약한다.
- Badukland는 교육 콘텐츠 화면, 공지 관리자 CRUD, MyBatis 연동을 요약한다.

## 검증

- 기존 프로젝트 상세 URL 세 개와 Plainpaper 상세 URL이 계속 동작해야 한다.
- 키보드만으로 경력 상세 모달을 열고 탐색하고 닫을 수 있어야 한다.
- 모바일 폭에서 프로젝트 요약과 기간이 겹치지 않아야 한다.
- 콘텐츠 검증, 테스트, TypeScript 빌드와 Vite 빌드가 모두 통과해야 한다.
